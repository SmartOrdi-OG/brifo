# بريفو على تيلغرام — خطوات التشغيل

الكود جاهز ومنشور. الباقي خمس خطوات بتتعمل مرة وحدة.
اللي بدك ياه: حساب تيلغرام، وحساب Vercel.

---

## ١. اعملي البوت عند BotFather

1. افتحي تيلغرام وابحثي عن **@BotFather** (اللي عليه علامة زرقاء).
2. اضغطي **Start**، وبعدين ابعتيلو:

   ```
   /newbot
   ```

3. رح يسألك عن **اسم** البوت — اكتبي:

   ```
   Brifo
   ```

4. رح يسألك عن **username** — لازم ينتهي بـ `bot` ويكون غير مستخدم. جرّبي:

   ```
   BrifoAustriaBot
   ```

   إذا محجوز، جرّبي `BrifoAppBot` أو `MyBrifoBot`.

5. رح يعطيكي رسالة فيها سطر شكلو هيك:

   ```
   123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

   **هاد هو الـ token.** انسخيه واحتفظي فيه — هو مفتاح البوت، ما تبعتيه لحدا.

---

## ٢. زبّطي شكل البوت (اختياري بس بينصح فيه)

كلها عند BotFather، وحدة وحدة:

```
/setdescription
```
بعدها اختاري البوت، وبعدين الصقي:
> صوّر أي رسالة ألمانية وابعتها، ورح أشرحلك شو فيها بلغتك، وأقلك شو المطلوب منك، وأذكّرك بالمواعيد.

```
/setabouttext
```
> بريفو — يقرأ رسائلك الألمانية ويشرحها بلغتك.

```
/setcommands
```
وبعدها الصقي هاد كلو مرة وحدة:

```
help - المساعدة
mawaid - مواعيدي المحفوظة
clear - مسح المواعيد
lang - تغيير اللغة
cancel - إلغاء كتابة الرد
```

---

## ٣. ضيفي المتغيرات على Vercel

روحي على **Vercel → مشروع brifo → Settings → Environment Variables**، وضيفي تلاتة
(اختاري **Production** لكل وحدة):

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | الـ token من خطوة ١ |
| `TELEGRAM_WEBHOOK_SECRET` | `1gpH3w1ENAvMeC2Gn_OYboLgDToJ9ON9` |
| `PUBLIC_BASE_URL` | `https://mybrifo.com` |

> الـ `TELEGRAM_WEBHOOK_SECRET` كلمة سر عشوائية عملتها إلك. ممكن تغيّريها لأي نص طويل،
> بس لازم تكون **نفسها بالضبط** بخطوة ٤.

البوت بيستعمل كمان `KV_REST_API_URL` و `KV_REST_API_TOKEN` — هدول موجودين أصلاً
(نفسهم يلي بيستعملهم التذكير بالتطبيق). إذا مش موجودين، البوت بينسى كل شي بعد كل رسالة.

---

## ٤. اعملي Redeploy وبعدين وصّلي البوت

1. على Vercel: **Deployments → آخر deployment → ⋯ → Redeploy**. استنّي لتخلص.

2. افتحي هاد الرابط بالمتصفح (بدّلي `<TOKEN>` بالـ token تبعك):

   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://mybrifo.com/api/telegram&secret_token=1gpH3w1ENAvMeC2Gn_OYboLgDToJ9ON9
   ```

   لازم يطلعلك:

   ```json
   {"ok":true,"result":true,"description":"Webhook was set"}
   ```

---

## ٥. تأكّدي إنو شغّال

افتحي بالمتصفح:

```
https://mybrifo.com/api/telegram
```

لازم يطلع:

```json
{"ok":true,"hasBotToken":true,"hasWebhookSecret":true}
```

إذا طلع `false` بوحدة منهم، يعني المتغير ما انحفظ أو ما عملتي Redeploy بعد ما ضفتيه.

بعدها افتحي البوت بتيلغرام واضغطي **Start**. جرّبي:

- `/start` → لازم يرحّب فيكي ويعطيكي أزرار اللغات
- ابعتي **صورة رسالة ألمانية** → لازم يقرأها ويشرحها
- اضغطي **✍️ اكتب رد بالألماني** → اختاري نوع الرد واكتبي التفاصيل
- `/mawaid` → لازم يعرض المواعيد يلي لقاها بالرسالة

## ٦. التطبيق جوّا تيلغرام (Mini App)

بعد ما يشتغل البوت، صار في زر **📱 افتح تطبيق بريفو** تحت رسالة `/start`، وبيفتح
بريفو كامل جوّا تيلغرام. الزر بيشتغل لحالو بدون أي إعداد إضافي — بس لازم يكون
`PUBLIC_BASE_URL` مضبوط على `https://mybrifo.com` (خطوة ٣).

عشان يصير في **زر ثابت** جنب مربع الكتابة كمان، روحي عند BotFather:

```
/setmenubutton
```

اختاري البوت، بعدين **Edit menu button URL**، والصقي:

```
https://mybrifo.com
```

وبعدها اسم الزر:

```
بريفو
```

### شغلات لازم تعرفيها عن الـ Mini App

- **تسجيل الدخول:** نفس الإيميل ورمز الستة أرقام. الرابط اللي بالإيميل ما بيزبط جوا
  تيلغرام (بيفتح متصفح تاني)، بس **الرمز بيزبط** — لهيك خليكي عالرمز.
- **التصوير:** جوا تيلغرام الكاميرا المدمجة ما بتشتغل (خاصة على آيفون)، فالتطبيق
  بيفتح كاميرا الموبايل الأصلية مباشرة. النتيجة نفسها.
- **الاشتراك:** ممنوع نبيع اشتراك جوا تيلغرام (قوانين آبل). صفحة الاشتراك بتعرض
  زر **افتح موقع بريفو** بيطلّعك عالمتصفح الحقيقي، وهناك بتكملي الدفع.
- **التذكيرات:** جوا تيلغرام ما في تنبيهات ويب. بس هاد مو مشكلة — **البوت نفسه**
  بيبعتلك التذكير كرسالة، وهي أفضل من تنبيهات الويب أصلاً.

## شو بيعمل البوت

| الميزة | التفاصيل |
|---|---|
| قراءة الرسائل | نفس المحرّك يلي بالتطبيق بالضبط (`/api/analyze`) — مافي نسختين ممكن تختلفوا |
| اللغات | عربي، ألماني، تركي، فارسي، إنجليزي، أوكراني |
| التذكيرات | بتوصل **كرسالة تيلغرام** قبل الموعد بيوم — بدون تثبيت التطبيق وبدون أذونات |
| الرد بالألماني | نفس السبع خيارات يلي بالتطبيق، وبيستعمل اسم المرسِل واسم الطفل من الرسالة |
| الحد اليومي | ١٠ رسائل لكل مستخدم باليوم. للتغيير: `TELEGRAM_DAILY_SCAN_LIMIT` على Vercel |

**التذكيرات بتنبعت مع الـ cron اليومي الموجود** (`/api/cron/send-reminders`, الساعة ٨ صباحاً
بتوقيت فيينا) — نفس الوقت ونفس الصياغة يلي بالتطبيق. ما في شي جديد لازم تفعّليه.

## شغلات لازم تعرفيها

**الخصوصية.** الصور بتمرق عبر سيرفرات تيلغرام. هاد فرق جوهري عن التطبيق، لأنه
بالتطبيق الصورة بتروح من الموبايل للسيرفر مباشرة. إذا في بيان خصوصية منشور،
لازم ينذكر فيه إنو في قناة عبر تيلغرام.

**البوت عام.** أي حدا بيلاقي اسمه بيقدر يستعمله، والقراءة بتكلّف على حساب Anthropic.
لهيك في حد يومي (١٠). راقبي الفاتورة أول أسبوع وزيدي أو نقّصي الرقم حسب الاستعمال.

**مافي اشتراك بالبوت.** بريفو على تيلغرام مجاني ضمن الحد اليومي. موضوع Stripe
ما إلو علاقة فيه إطلاقاً — يعني البوت بيقدر ينطلق **قبل** ما تخلص توثيق Stripe.

**لإيقاف البوت مؤقتاً:** احذفي `TELEGRAM_BOT_TOKEN` من Vercel واعملي Redeploy.
لإيقافه نهائياً: `/deletebot` عند BotFather.
